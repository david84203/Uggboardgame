# 06 · 文案與導流：立牌、六格選單、報告 CTA、分享語錄

對應 Han 提供的「提示詞 B / C」。重新評估後的調整：

| 提示詞的假設 | 本專案的做法 | 原因 |
|---|---|---|
| 導流三條：保養品、彩妝課、**寫真拍攝** | 「預約寫真拍攝」已定案為第 4 個 CTA（Han 決策） | 照相館是本業，且診斷結果天然導向「拍一組符合你色彩型的照片」；實作成本為零（同 oaMessage 機制） |
| 「免費小測驗」定位 | 沿用「免費」，但把名稱定為**診斷**而非測驗 | 「測驗」像心理測驗，「診斷」才有專業感與導購正當性 |
| 文案由 AI 一次生成 | 提供 2 到 3 個版本供 Han 挑選，並附選擇理由 | 語氣最終要像 Han 本人 |

> 命名待 Han 決定，本文暫用「**AI 命定妝容診斷**」。備選：「韓系命定風格診斷」「90 秒找到你的命定色」。

## 1. 照相館現場立牌（梳化台 / 櫃檯）

Han 決策：做兩塊，**櫃檯用 A 版**（等待時間切入）、**梳化台用 B 版**（好奇心切入）。尺寸建議 A5 桌立牌，QR 佔三分之一，文字不超過 4 行。QR 分別連到 `?ref=store_counter` 與 `?ref=store_makeup`，之後可比較兩個位置的掃碼率。視覺沿用 Han 官方帳號選單的風格：米杏色底、深棕文字、細襯線中文字、標題上下加「✦」與細線裝飾。

**版本 A：櫃檯（等待時間切入）**
```
等叫號的 90 秒
讓 AI 告訴你：你的臉型、命定色、腮紅該打哪
掃碼免費診斷 → 拍完照直接拿報告
```

**版本 B：梳化台（好奇心切入）**
```
你是春夏秋冬哪一型？
拍一張自拍，AI 幫你找到命定妝容與穿搭色
免費・90 秒・報告存在你的 LINE
```

**版本 C：專業背書切入（備用，未採用）**
```
化妝師的眼睛，現在在你手機裡
臉型 × 五官量感 × 個人色彩，一張自拍全部診斷
掃碼免費體驗，梳化前先知道自己適合什麼
```

B 版（梳化台）底部加一行：「今天的妝，可以照報告來畫」，把診斷和當下的服務接起來。

## 3. 報告頁 CTA 文案

原則：按鈕文字是「我要做什麼」，不是「你來買」。每個 CTA 上方一句「為什麼推薦給你」，把診斷結果嵌進去（用變數）。

### 3.1 推薦保養 / 彩妝
- 引言：「依你的{{skin_type}}與{{season}}型，Han 從型錄挑了這 4 件：2 件保養、2 件彩妝」
- 商品卡各附一句理由（由對照表 `note` 欄或 AI `care_focus` 帶入），例如「舒緩泛紅・適合混合肌」
- 主按鈕：**「我想了解這 4 件」** → oaMessage 預填
  ```
  我想了解這幾件 🛍️
  ・{{product1}}
  ・{{product2}}
  ・{{product3}}
  ・{{product4}}
  【我的診斷】{{face}}｜{{season}}型｜{{skin}}
  報告編號：{{analysisId}}
  ```
- 次按鈕（有網址時）：「看商品」

### 3.2 預約一對一彩妝課
- 引言：「{{face_shape}}的腮紅畫法，30 分鐘就能上手」（依臉型帶入畫法關鍵字）
- 主按鈕：**「我想預約彩妝課」** → oaMessage 預填（見 02 文件 4.5 節）
- 補一句降低門檻的話：「先問問時間與價格，不用馬上決定」

### 3.3 預約寫真拍攝（已定案新增）
- 引言：「{{season}}型最上鏡的色系是{{recommended[0].name}}，要不要拍一組？」
- 主按鈕：**「我想預約拍照」** → oaMessage 預填
  ```
  我想預約拍照 📷
  想拍：證件照 / 形象照 / 個人寫真（請留一個）
  【我的診斷】{{face}}｜{{season}}型｜適合色：{{rec1}}、{{rec2}}
  報告編號：{{analysisId}}
  ```

### 3.4 IG 限動分享
- 引言：「把你的命定色貼到限動，讓朋友也來測」
- 主按鈕：**「做成限動卡」**
- 卡片產出後的兩個按鈕：「儲存圖片」「傳到聊天室」
- 分享卡固定角落：店家 LINE QR + 「掃我測你的命定色」

### 3.5 傳到聊天室
- 按鈕：「把報告存到 LINE」
- Flex Message 文案：
  ```
  {{headline}}
  臉型 {{face}}・量感 {{volume}}・{{season}}型・{{skin}}
  {{body}}
  [看完整報告] [預約彩妝課] [我想了解商品]
  ```

## 4. 分享卡與限動語錄

分享卡 1080×1920，上方是 headline 與 3 到 6 個標籤，中間是臉型線稿 + 季型色票，下方是語錄與 QR。語錄依季型自動帶入，每型準備 3 句輪播：

| 季型 | 語錄 |
|---|---|
| spring | 「原來我是春天，難怪珊瑚色一擦就發光」／「暖亮春季型，今天起告別冷灰色」／「AI 說我是春天，我信了」 |
| summer | 「夏季型的我，玫瑰色才是本命」／「柔霧夏日，藕粉比正紅更像我」／「終於知道為什麼黑色讓我看起來累」 |
| autumn | 「秋季型認證：楓葉紅、焦糖、橄欖綠，全部收」／「暖調濃郁，大地色是我的主場」／「原來磚紅唇才是我的顏色」 |
| winter | 「冬季型，正紅與純白都駕馭得了」／「高對比冷色，我的顏色很有態度」／「莓果色，一擦就對」 |

通用結尾（固定）：「你是哪一型？掃碼 90 秒找答案」

## 5. 流程中的微文案

| 位置 | 文案 |
|---|---|
| 歡迎頁標題 | 「一張自拍，找到你的命定妝容」 |
| 歡迎頁副標 | 「AI 分析臉型、五官量感、個人色彩，Han 幫你把畫法畫給你看」 |
| 同意勾選 | 「我同意照片僅用於本次分析，分析後即刪除原圖，只保留文字結果」 |
| 拍照指引 3 句 | 「正對鏡頭」「面向光源」「露出額頭與下顎線」 |
| 品質不合格 | 見 05 文件 4.1 |
| 等待頁分步 | 「正在看你的臉型輪廓…」「正在判斷冷暖底色…」「正在幫你挑腮紅位置…」「快好了，正在整理報告」 |
| 報告總結卡 | `{{headline}}` + `{{body}}` |
| 圖解區說明 | 「點一下切換腮紅、修容、打亮，每一層都有畫法說明」 |
| 低信心度 | 「你介於 A 與 B 之間，這次以 A 的畫法為主，也可以切到 B 看看」 |
| 濃妝提示 | 「這張照片有濃妝或濾鏡，色彩與膚質判斷僅供參考，想更準可以用素顏照再測一次」 |
| 次數用完 | 「今天的三次分析用完了，明天再來；先把報告存到 LINE 吧」 |
| 回饋 | 「這份分析準嗎？」👍「很像我」👎「不太像」 |
